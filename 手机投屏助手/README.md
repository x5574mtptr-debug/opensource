# 手机投屏助手

Windows 端的手机投屏与远程操作工具。投屏内核用 **scrcpy**，界面用 **PyQt5**，经 PyInstaller 打包成**单个 exe**，解压双击即用，不需要装 Python、scrcpy 或 adb。

## 功能

- **投屏操作**：手机画面实时投到电脑，鼠标键盘可直接操作手机
- **投屏并录屏**：投屏同时把画面录成 mp4
- **保存截图**：把当前手机画面存成图片
- **无线连接**：先用数据线连一次，之后手机与电脑在同一 WiFi 下即可无线投屏，拔线继续用
- **文件传输**：电脑文件拖进窗口即发送到手机；手机文件可拖出到桌面，也可在列表里选中后下载；支持浏览手机目录、回车跳转路径
- **中文输入**：scrcpy 原生只能直接打英文，这里可把中文/长文本发送到手机当前光标处，也可把键盘模式切成「中文 · 手机输入法」
- **安装应用**：选一个 apk 安装到手机
- **重启连接**：检测不到设备时重启调试服务
- **切换设备**：多台手机之间切换投屏/操作目标
- **投屏时关闭手机屏幕**：省电，手机端黑屏但电脑端仍可操作
- **运行日志**：折叠面板，连接与命令输出都在里面

## 使用

1. 解压压缩包，双击 `手机投屏助手.exe`
2. 手机开启「开发者选项 → USB 调试」，用数据线连电脑
3. 手机上弹出授权框时点「允许」
4. 点「开始投屏」

无线投屏：先用数据线连接一次，保持手机与电脑在同一个 WiFi，再点「连接 WiFi」，成功后即可拔掉数据线。

## 打包说明

- 平台：Windows x64
- 内置 scrcpy、adb（platform-tools）、FFmpeg 运行库，所以单文件体积较大（压缩包约 53 MB）
- 首次运行若被 SmartScreen 拦截，选择「更多信息 → 仍要运行」即可

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 提示「未检测到设备」 | 检查数据线是否支持数据传输、USB 调试是否已开，再点「重启连接」 |
| 提示「未找到投屏内核」 | 压缩包不完整，重新解压全部文件后再运行 |
| 无线连接失败 | 确认手机与电脑在同一 WiFi，或改用手机热点后重试 |
| 中文打不进去 | 用「输入中文」发送，或把键盘模式切到「中文 · 手机输入法」 |
